# VLOOKUP Practice

## Topics Covered

- VLOOKUP
- Exact Match
- Absolute Cell References
- Multiple Column Lookups
- IFERROR with VLOOKUP
- Handling Missing Product IDs
- Basic Revenue Calculation

## Practice Dataset

The exercise uses two tables:

- Orders table
- Products table

VLOOKUP was used to retrieve:

- Product Name
- Category
- Price

## Additional Analysis

Revenue was calculated using:

Revenue = Quantity × Price

## Error Handling

IFERROR was used to display `Not Found` when a Product ID did not exist in the Products table.

- Excel Lookup Functions

- Basic Business Analysis
