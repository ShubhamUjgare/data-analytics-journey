# 🔎 SQL Filtering

This folder contains my SQL practice on filtering data using the `WHERE` clause.

The focus is on retrieving only the records that match specific conditions, which is an essential skill for Data Analyst roles.

---

## 🎯 Learning Objective

Learn how to:

- Filter rows using `WHERE`
- Compare numeric values
- Compare text values
- Use comparison operators
- Combine multiple conditions
- Filter data using `AND` and `OR`
- Write practical filtering queries

---

## 📚 Topics Covered

### 1. WHERE

Used to filter records based on a condition.

```sql
SELECT *
FROM employees
WHERE department = 'IT';
